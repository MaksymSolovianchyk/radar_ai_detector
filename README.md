## REPOSITORY STRUCTURE
### stm32ai-modelzoo-services/
Official STMicroelectronics repository used for:
- Training AI models
- Converting models to optimized C code
- Deploying models to STM32 boards
- STM32N6 deployment

This folder contains deployment pipelines and application code templates.
---
### stm32ai-modelzoo/
Official ST model repository containing:
- Pretrained models
- Reference architectures
- Example model configurations
- Dataset configurations
---
### ultralytics/
Local copy of the Ultralytics repository.
Used for:
- YOLO model training
- Custom object detection experiments
- Dataset annotation compatibility
---
### docs/
Documentation folder containing project-related materials.

Includes:
- Project descriptions and methodology explanations
- Architecture diagrams and system overviews
- Notes on experiments and testing procedures
- Setup and usage instructions
Used for:
- Keeping structured documentation of the project  
- Supporting report writing and knowledge transfer  

---

### recorded_data/
Folder containing raw data collected during experiments.

Includes:
- Sensor recordings (e.g., radar signals)
- Captured frames or measurement logs
- Data used to generate training datasets (e.g., waterfall images)

Used for:
- Creating datasets for model training  
- Reproducing experiments  
- Analyzing system behavior and performance
